# Supplementary Material for Thermodynamic modeling tools for the interpretation of melt inclusions and volcanic gases
This repository contains all materials needed to reproduce calculations and figures in the manuscript "Thermodynamic modeling tools for the interpretation of melt inclusions and volcanic gases" submitted to Volcanica July 2026. 

The as-yet un-peer reviewed pre-print can be found on EarthArXiv: https://doi.org/10.31223/X59B79

Full citation:
Iacovino, K., Hughes, E., Burgisser, A., Ding, S., Kilgour, G., Liggins, P., Sun, C., and Wieser, P. (2026) Thermodynamic modeling tools for the interpretation of melt inclusions and volcanic gases, EarthArXiV pre-print, https://doi.org/10.31223/X59B79
