# Supplementary Material for Thermodynamic modeling tools for the interpretation of melt inclusions and volcanic gases
This repository contains all materials needed to reproduce calculations and figures in the manuscript "Thermodynamic modeling tools for the interpretation of melt inclusions and volcanic gases" submitted to Volcanica July 2026. Full citation:

Iacovino, K., Hughes, E., Burgisser, A., Ding, S., Kilgour, G., Liggins, P., Sun, C., and Wieser, P. (submitted) Thermodynamic modeling tools for the interpretation of melt inclusions and volcanic gases.
